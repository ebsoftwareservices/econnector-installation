## One-line install

Latest release:

  curl -fsSL https://raw.githubusercontent.com/ebsoftwareservices/econnector-installation/main/linux/install-from-release.sh | sudo bash

Specific release tag:

  curl -fsSL https://raw.githubusercontent.com/ebsoftwareservices/econnector-installation/main/linux/install-from-release.sh | sudo bash -s -- v1.2.3

After installation, configure credentials (see below).

## Manual install

Download `econnector-installation-linux.tar.gz` from GitHub Releases, extract it, then run:

  sudo ./install.sh

## Configure Credentials

After installation, run:

  sudo /opt/econnector/configure-credentials.sh

Enter the Client ID and Client Secret when prompted.

## Service Management

  systemctl status econnector
  systemctl stop econnector
  systemctl start econnector
  systemctl restart econnector

## Logs

Check logs in `/opt/econnector/econnector-daemon-logs/`.

## Upgrade

If installed from a tarball, run from the extracted package directory:

  sudo ./upgrade.sh

Or pass a tag:

  sudo ./upgrade.sh v1.2.3

## Uninstall

From an extracted package directory:

  sudo ./uninstall.sh
