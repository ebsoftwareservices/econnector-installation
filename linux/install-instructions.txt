## One-line install

Latest release:

  curl -fsSL https://raw.githubusercontent.com/ebsoftwareservices/econnector-installation/refs/heads/main/linux/install-from-release.sh | sudo bash

Specific release tag:

  curl -fsSL https://raw.githubusercontent.com/ebsoftwareservices/econnector-installation/refs/heads/main/linux/install-from-release.sh | sudo bash -s -- v1.2.3

After installation, configure credentials (see below).

## Manual install

Download `econnector-installation-linux.tar.gz` from GitHub Releases, extract it, then run:

  sudo ./install.sh

## Configure Credentials

After installation, run:

  sudo /opt/econnector/configure-credentials.sh

Enter the Client ID and Client Secret when prompted.

## Service Management

  systemctl status econnector
  systemctl stop econnector
  systemctl start econnector
  systemctl restart econnector

## Logs

Check logs in `/opt/econnector/econnector-daemon-logs/`.

## Upgrade

  sudo /opt/econnector/upgrade.sh

Or pass a release tag:

  sudo /opt/econnector/upgrade.sh v1.2.3

## Uninstall

  sudo /opt/econnector/uninstall.sh
